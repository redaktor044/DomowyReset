# DOMOWY RESET — Website Designer / UI·UX Standard

## Art direction
- 2026 editorial interior/lifestyle magazine; never generic AI-template aesthetics.
- Reference hierarchy: utility strip → editorial masthead → integrated primary navigation → hero + supporting stories → circular topic navigation → latest articles → editorial/affiliate modules → footer.
- Use restrained warm neutrals, olive utility accents and terracotta CTA accents.
- Photography should feel natural, architectural, warm, premium and people-free unless the content specifically requires people.

## Typography
- Display: DM Serif Display.
- UI/body: DM Sans.
- Strong typographic hierarchy; generous whitespace; avoid excessive rounded cards/pills.

## Layout rules
- Desktop-first editorial grid with clear alignment and consistent max-width.
- Navigation belongs visually to the masthead, not as an isolated app-like bar.
- Hero is the primary visual anchor.
- Topic/category navigation follows the hero.
- Avoid decorative elements that do not improve hierarchy, navigation or conversion.
- Mobile must preserve editorial hierarchy and readable tap targets.

## UX / conversion
- Clear primary CTA.
- Affiliate content should lead through useful editorial content before product recommendations.
- Every section needs a clear purpose and visual hierarchy.
- Prioritize readability, accessibility, performance and semantic HTML.

## Quality gate
Before delivery check: visual hierarchy, grid consistency, typography, spacing, responsive behavior, accessibility, loading/performance, navigation clarity and conversion intent.
